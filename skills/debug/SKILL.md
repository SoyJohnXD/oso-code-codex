# Debug

Read [execution](../../references/execution.md), [runtime](../../references/runtime.md), and the [rubric](../../references/rubric.md). Before product edits, start or resume the authorized runtime; reconstruct it only when its record is unavailable, from the absolute project, run id, literal Engram topic and actual approval reference. Preserve missing indispensable identity or authority as the precise pending item. Keep reproduction, diagnosis, repair and regression verification in the same task. The principal owns decisions, integration and closure. Keep tiny, already-understood fixes local; delegate substantial independent investigation, implementation or corrections under [model selection and escalation](../../references/execution.md#model-selection-and-escalation).

Use [shared Engram memory](../../references/engram.md) to recover preferences and an existing diagnosis. Save the evidenced diagnosis before repair, merge substantive corrections and save the outcome or paused next step to the same change's summary. Debug creates no artificial plan/index row or operational Markdown.

Capture the observed failure and expected behavior. Inspect the actual failing path and its callers before choosing a cause. Distinguish a product defect from missing infrastructure/permissions or incomplete delivery. Permission, tool or infrastructure errors do not justify model escalation.

For a new specification, record the approved child coordination and any approved actual review fallback. Existing records retain their compatible accounting rather than receiving retroactive configuration data.

Explain the evidenced cause and proposed repair, then continue within the authorized bug-fix scope. Do not insert a routine diagnosis approval. A newly discovered material product or architecture decision follows the existing authority boundary.

Obtain a real failing reproduction before the fix where feasible; preserve its output. If reproduction is blocked, state what evidence is missing. Never reconstruct or label a post-fix run as a historical red test.

Make the smallest coherent fix across the affected pattern. Add a regression test that would fail for the bug, and run affected project checks through the evidence runner. Use one independent final reviewer under [model selection and escalation](../../references/execution.md#model-selection-and-escalation) for the full assigned behavior, rubric and conformance surface. That reviewer should challenge the proposed cause and test coverage, including a relevant edge case, and batch supported findings for correction and directed confirmation.

New approved AUTO debug work uses the policy in [runtime](../../references/runtime.md). Retain an existing run's policy until explicit adoption under actual applicable authority. For adoption or a correction pause, follow [correction recovery](../../references/correction-recovery.md) in the same block: two corrections without qualifying progress call for autonomous diagnosis and a changed strategy, while explicit limits and native permissions remain binding. Retain the diagnosis, owned resources and precise next step; no unchanged relaunch or replacement run. Close after current evidence and independent review pass.
