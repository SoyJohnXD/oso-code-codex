# Doubt pass

Read only the approved intent, surface map and bare decisions. The author's rationale is deliberately absent to reduce anchoring. Judge whether the decisions satisfy the stated contract: uncovered surfaces, unsupported assumptions, ignored failure modes and simpler reversible alternatives.

Review only. Do not edit, delegate recursively, save memory or ask the user questions. If launched as a child, use [model selection and escalation](../../references/execution.md#model-selection-and-escalation). Report each surviving concern with the affected decision and concrete consequence. Do not classify concerns as noise/actionable; the principal reconciles them against the recorded rationale.

Return clean, findings or a specific missing-evidence condition in ordinary prose. Missing wrapper labels are not substantive blockers when the actual inputs are present. A single pass is the default; repeat only after a material decision change or a focused unanswered concern. Do not run repeated clean passes.
